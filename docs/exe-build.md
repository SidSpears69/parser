# Сборка и проверка WebParser.exe

Сборка выполняется в Windows под Python 3.14 x64. Для развёртывания на Windows Server 2019 соберите и проверьте exe непосредственно на этом сервере. Подготовьте `.venv` по [инструкции для Windows Server](windows-server-2019.md), затем из корня проекта выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_exe.ps1 -Browser "Яндекс Браузер"
```

Скрипт устанавливает закреплённые версии PyInstaller и его хуков, собирает приложение в `dist\WebParser` и запускает проверку готового exe. Успех подтверждается строкой `SELF TEST PASSED` в `dist\WebParser\artifacts\self-test.txt`. Проверка открывает окно приложения и выбранный браузер с временным профилем, запускает драйвер Playwright и не обращается к сайтам.

Для переноса скопируйте **весь каталог** `dist\WebParser`, сохранив его структуру. Запускайте `WebParser.exe` в интерактивной сессии Windows. На целевой машине должны быть установлены выбранный браузер и необходимые системные библиотеки; Python и `.venv` для запуска exe не требуются. Для Firefox сборка Playwright устанавливается отдельно под той учётной записью Windows, которая запускает exe. [Правила упаковки Playwright](https://playwright.dev/python/docs/library#pyinstaller), [расположение браузеров Playwright](https://playwright.dev/python/docs/browsers).

Каталог `dist\WebParser` создаётся заново при повторной сборке. Для длительной работы запускайте копию в отдельном каталоге. Скрипт останавливает повторную сборку, если найдёт сохранённые данные в `dist\WebParser`.

Если в прежнем каталоге `dist\WebParser` уже есть результаты работы, соберите новую версию отдельно: добавьте к команде `-BuildChannel update`. Готовый комплект появится в `dist\update\WebParser`, а прежний останется на месте.

На целевой машине повторите проверку без Python:

```powershell
.\WebParser.exe --self-test --browser "Яндекс Браузер"
Get-Content .\artifacts\self-test.txt
```

Рабочие изображения и журналы сохраняются в `artifacts` рядом с exe; у учётной записи должны быть права на запись в эту папку. Конфигурацию загрузите через кнопку приложения. Секреты в файле настроек защищены Windows DPAPI, поэтому файл, сохранённый на другой машине или под другой учётной записью, может не расшифроваться. В таком случае настройте и сохраните его на целевой машине.

Автопроверка подтверждает упаковку Qt, Playwright и запуск браузера. Для проверки обработки данных выполните в приложении один прогон с рабочим JSON, прокси и FTP и проверьте результаты, журнал, сохранённые фото и файл `processed_products.json` на FTP. Доступ к маркетплейсам, капчи и FTP зависят от целевой машины и не подтверждаются локальной сборкой.
